## ¿Qué es Git?

Git es una herramienta que permite a un equipo de programadores trabajar en conjunto sobre un mismo proyecto, además de consultar trabajos de otros, aprender y tener organización de código.

## Por qué necesitamos Git

Es una herramienta útil que permite resolver situaciones de código sin necesidad de crear uno nuevo para conservar parte del anterior, no se si me explique, yo lo hacia, además permite trabajar en equipo a distancia y resolver problemas como volver a una rama anterior de codigo.

## Los 3 conceptos clave de Git

1. **Repositorio:** Me gustaria llamarlo una carpeta donde se localiza un proyecto y sus archivos.
2. **Commit:** Con un commit puedes ir guardando tus cambios del proyecto y escribir un mensaje sobre dichos cambios.
3. **Rama:** Un trabajo independiente de un mismo proyecto que permite no dañar el principal.
